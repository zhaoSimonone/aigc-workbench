## 二、必须实现

### A. 在 AIGC 工作台配置百度 Token（加密、用途、过期、刷新）

Token **必须能在网页「工作文档」里配置**，不要只靠环境变量或本机文件。

1. `server/schema.sql` 增加 `netdisk_credentials`（见方案 §3.2），含 `scope`、`expires_at`，`status` 为 `active|invalid|expired`。`IF NOT EXISTS`。
2. 环境变量 `NETDISK_TOKEN_ENCRYPTION_KEY`：32 字节 Base64。解码后必须是 32 bytes，否则拒绝保存。
3. AES-256-GCM，密文格式 `v1.<iv_b64>.<tag_b64>.<ciphertext_b64>`。
4. PUT 入参是 `{ credential }` 或 `{ accessToken }`，粘贴体最长 2048。服务端必须能解析三种输入：
   - 整段 `https://openapi.baidu.com/oauth/2.0/login_success#expires_in=2592000&access_token=...`
   - 仅 hash 片段 `#expires_in=...&access_token=...`
   - 纯 Token
   Token 在 `#` 后面，不在 `?` query。解析出 `expires_in`（默认 2592000）、`scope`。完整 URL 不得入库、不得写日志。示例里只用 `<TOKEN>` 占位，测试夹具用假 Token，禁止提交真实授权回调。
5. API（均 `requireUser`）：
   - `GET /api/netdisk/credential` → `{ configured, status, tokenLast4, scope, obtainedAt, expiresAt, expiresInSec, lastVerifiedAt, lastError, purpose, authorizeUrl }`，**无 Token**。若已过 `expiresAt`，即使库内是 active 也返回 `expired`。
   - `PUT /api/netdisk/credential`：解析 → 加密 upsert → `list /AIGC` 探活；errno 111 不算成功。
   - `DELETE /api/netdisk/credential`：删凭据，不删 `netdisk_nodes`
6. `purpose` 固定文案：`仅用于读取百度网盘 /AIGC 目录列表，不会用此 Token 上传、下载或删除文件。`
7. `GET /api/netdisk/options` 返回同一条 `authorizeUrl`：
   `https://openapi.baidu.com/oauth/2.0/authorize?response_type=token&client_id=QHOuRXiepJBMjtk0esLhrPoNlQyYd0mF&redirect_uri=oob&scope=basic,netdisk&qrcode=1`
8. 过期检测：`now >= expires_at` 时不要用这枚 Token 打百度，直接 `expired` + 缓存目录。剩余 ≤ 3 天要在 GET 里能算出来（前端用 `expiresAt`）。errno 111 → `invalid`。
9. 刷新：不实现 refresh_token。用户重新授权，再 PUT 覆盖。回调里 `session_key`/`session_secret` 为空是正常的。
10. 禁止通用网站 Token 表，禁止 `provider` 自由扩展。

### B. 实时 list 一层目录

1. 新建 `server/src/netdisk-live.js`（或同等模块），**只实现 list**（可选 quota）。禁止 precreate / superfile2 / filemanager / create / 下载。
2. 与 Python 保持一致：
   - `GET https://pan.baidu.com/api/list`
   - `dir, web=1, page, num=1000, order=name, desc=0`
   - 同层翻页直到 `< 1000`
   - 可重试 errno：`-6,-8,-11,112,158`，最多 4 次
   - 单次 HTTP 超时 8s，整层 15s
3. 路径必须 `assertNetdiskPath`，默认根 `/AIGC`。
4. 清洗节点，字段与现有 `publicNode` 对齐；丢掉 thumbs/dlink/md5/凭据。`fsId` 用字符串。
5. 改造 `GET /api/netdisk/children` 与 `GET /api/netdisk/tree`（都是一层，不是递归）：
   - 有 active 凭据 → 实时 list → upsert 这一层到 `netdisk_nodes` → 删掉该 `parent_path` 下未出现的节点；若未出现的是目录，删除其子孙（LIKE 要 ESCAPE 并转义 `%`/`_`）
   - 成功：`source: "live"`，带 `fetchedAt`
   - 失败：有缓存则 `source: "cache"` + `warning`；errno 111 标凭据 `invalid` 并给 `errorCode: "token_invalid"`
   - 无凭据：不打百度，返回缓存或空，`credential.configured=false`
6. **禁止**打开页面就递归 tree 整盘。
7. `GET /api/netdisk/search`、`GET /api/netdisk/stats` 继续只读 `netdisk_nodes`（缓存）。
8. `POST /api/netdisk/catalog` 和 `publish-catalog` **保留**，作为离线暖缓存。实时 list **不要**走 `complete=true` 清空整棵树。
9. 日志只打 path、errno、条数。禁止打印 URL（query 里有 token）、禁止打印 Token、禁止打印 dlink。

## 五、接口契约（给前端）

`GET /api/netdisk/children?path=/AIGC/902视频`

```json
{
  "path": "/AIGC/902视频",
  "source": "live",
  "fetchedAt": "2026-10-12T08:40:00.000Z",
  "warning": "",
  "errorCode": "",
  "credential": { "configured": true, "status": "active", "tokenLast4": "ab12" },
  "nodes": [
    {
      "path": "/AIGC/902视频/成片",
      "name": "成片",
      "parentPath": "/AIGC/902视频",
      "isDir": true,
      "kind": "directory",
      "sizeBytes": 0,
      "serverMtime": "2026-10-12T07:00:00.000Z",
      "fsId": "964775760105555",
      "category": 6
    }
  ],
  "snapshot": null
}
```

`source` 只允许 `live | cache | none`。失败时尽量 HTTP 200 + `errorCode`，方便前端同时画列表和警告。`errorCode` 建议：`need_credential`、`token_invalid`、`live_unavailable`、`encryption_key_missing`。

节点数组里禁止出现：`access_token`、`dlink`、`thumbs`、`md5`、`cookie`。
