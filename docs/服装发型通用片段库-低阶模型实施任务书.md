## 一、用户场景

创作者做蕾姆风变装视频时，需要独立检索：

1. 衣服长什么样 → 服装库
2. 头发是什么款 → 发型库
3. 已经剪好、可直接叠进成片的前段/换装片段 → 通用片段

当前这些东西混在角色设定或本机目录里，上传时还经常带着 `WechatIMG848.jpg` 这种无意义文件名。
