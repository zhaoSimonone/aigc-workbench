# 百度网盘目录服务端实时读取方案

> 本文是对 `docs/百度网盘目录渲染与本地MCP归档-方案设计.md` 的**增量修正**，只改「工作台怎么读目录」，不改上传/下载通路。
>
> 实现时请同时参考：`docs/百度网盘目录服务端实时读取-低阶模型实施任务书.md`。
>
> 上一版规定「服务器不得持有百度 Token」。本版**有限度放开**：服务器可以加密保存当前登录用户的百度 Access Token，但**只允许调用 list**。上传、下载、删除、在线播放、文件中转仍然禁止。

## 0. 为什么改

上一版工作文档只能渲染本机 MCP/CLI 发布的目录快照。网盘里已经有 `/AIGC/902视频` 时，若没人执行 `publish-catalog`，页面就是空的。

当前 `/AIGC` 实测规模很小：6 个目录、26 个文件，整棵树的目录 JSON 约 11 KB；点进一层通常不到 10 个节点。实时 `list` 的延迟和数据量都不是问题。真正大的是视频字节，下载继续走本机。

因此改为：

| 内容 | 谁做 | 经过工作台服务器吗 |
| --- | --- | --- |
| 打开/点击文件夹，看目录 | 工作台服务器调百度 `GET /api/list` | 只经过元数据 JSON |
| 上传创作目录到 `/AIGC` | 本机 Skill/CLI | 否 |
| 把网盘文件下载回本机 | 本机 Skill/CLI | 否 |
| 视频/图片原片 | 只存在百度网盘 | 否 |

## 1. 目标与边界

### 1.1 目标

1. 已登录用户在 AIGC「工作文档」页配置百度网盘 Token（可贴授权成功后的整段回调地址，或只贴 access_token）。
2. 页面必须写明 Token 用途：只给工作台读取 `/AIGC` 目录列表，不用来上传、下载、删除；视频仍走本机 Skill。
3. 保存后打开 `/AIGC`、点击子目录，都能看到网盘当下的内容；点「刷新」重新 list，不必先跑 `publish-catalog`。
4. Token 加密存放，按工作台用户隔离；接口和日志永不回显明文，也不回显完整授权回调 URL。
5. 能检测过期：保存 `expires_in`（百度回调里通常是 2592000 秒 = 30 天）；剩余不足 3 天警告，过期或百度 errno 111 则引导重新授权。
6. 过期后只能**重新打开授权页 → 再复制回调地址 → 覆盖保存**。当前是 `response_type=token` 隐式授权，回调没有可用的 refresh_token，不要做自动续期。
7. 百度超时、Token 失效时，降级显示已缓存的 `netdisk_nodes`，并标明不是实时结果。
8. 上传/下载命令仍展示，但降为辅助，不再是看到目录的前提。
9. 「工作文档」页去掉旧版对象存储归档入口，并删除对应前后端代码。

### 1.2 非目标

- 不做通用「网站 Token 仓库」。只存百度网盘这一枚 Access Token。
- 不在服务器上上传、下载、删除网盘文件，不中转 dlink，不在网页里播放网盘原片。
- 不在打开页面时递归遍历整棵 `/AIGC`。只 list 当前这一层，翻页拉完。
- 不把搜索做成实时全盘递归。搜索和统计继续走本地缓存表。
- 不引入 refresh_token 自动续期，也不要调用百度 refresh 接口。授权回调里 `session_key` / `session_secret` 通常为空，过期只能让用户重新授权。
- 不改素材库、音乐库、提示词、人物相册、视频账号，以及素材上传 COS 的现有链路。
- **要删除**旧版「对象存储归档」（扫描本机目录 → 服务器上传 COS/local）。这不是素材库，不要误删 `/api/assets`。

## 2. 总体架构

```text
浏览器 /documents
    │  只传路径，不传 Token，不传文件
    ▼
工作台 API（Node）
    │  解密当前用户的百度 Token（仅内存中使用）
    │  GET https://pan.baidu.com/api/list?dir=/AIGC/...
    ▼
百度开放平台（只读 list）
    │  目录节点 JSON（无文件字节）
    ▼
清洗后返回前端，并写入 netdisk_nodes 作缓存

本机 Skill/CLI ──上传/下载字节──► 百度网盘 /AIGC
```

三条通路仍然分离：

1. **字节通路**：本机 ↔ 百度网盘。服务器不参与。
2. **实时目录通路**：浏览器 → 工作台 → 百度 list → 浏览器。只含元数据。
3. **缓存通路**：`netdisk_nodes` / `netdisk_snapshots`。实时成功后更新；实时失败时兜底。

上一版的 `POST /api/netdisk/catalog` 和 `publish-catalog` **保留**，作为离线暖缓存和本机工具，不再是网页能看到目录的前提。

## 3. Token 怎么存

### 3.1 原则

- 每个工作台用户最多一枚百度网盘 Token（`UNIQUE(user_id)`）。
- 数据库只存密文，不存明文，不存 dlink。
- 加密主密钥来自服务器环境变量 `NETDISK_TOKEN_ENCRYPTION_KEY`，不进 Git、不进前端、不进数据库。
- `GET` 凭据接口只返回「有没有、状态、后四位、时间」，绝不返回 Token。
- 本机 Skill 的 Token 文件保持原样，给上传/下载用；与服务器这枚可以相同，但服务器不读取本机文件。

### 3.2 表 `netdisk_credentials`

```sql
CREATE TABLE IF NOT EXISTS netdisk_credentials (
  user_id UUID PRIMARY KEY REFERENCES users(id) ON DELETE CASCADE,
  provider TEXT NOT NULL DEFAULT 'baidu_netdisk'
    CHECK (provider = 'baidu_netdisk'),
  encrypted_token TEXT NOT NULL,
  token_last4 TEXT NOT NULL DEFAULT '',
  scope TEXT NOT NULL DEFAULT '',
  status TEXT NOT NULL DEFAULT 'active'
    CHECK (status IN ('active','invalid','expired')),
  expires_at TIMESTAMPTZ,
  last_error TEXT NOT NULL DEFAULT '',
  obtained_at TIMESTAMPTZ NOT NULL DEFAULT now(),
  last_verified_at TIMESTAMPTZ,
  updated_at TIMESTAMPTZ NOT NULL DEFAULT now()
);
```

`encrypted_token` 格式（UTF-8 文本，不要用 JSON 包一层 Token）：

```text
v1.<iv_b64>.<tag_b64>.<ciphertext_b64>
```

- 算法：AES-256-GCM
- 密钥：`NETDISK_TOKEN_ENCRYPTION_KEY`，必须是 32 字节的标准 Base64（解码后 32 bytes）
- IV：12 字节随机
- 明文：Access Token 字符串，trim 后写入
- 缺密钥或密钥长度不对：拒绝保存凭据，实时 list 直接报「服务器未配置加密密钥」，不要明文兜底写入数据库

`token_last4` 只存 Token 末 4 个字符，给用户确认「是不是刚贴的那枚」。不要存更多。`scope` 只存回调里的 `scope`（如 `basic netdisk`），没有就空串。

### 3.3 用户贴什么：Token 或整段回调地址

百度是隐式授权。用户打开授权页，登录后跳到类似：

```text
https://openapi.baidu.com/oauth/2.0/login_success#expires_in=2592000&access_token=<TOKEN>&session_secret=&session_key=&scope=basic+netdisk
```

文档和代码示例里必须用 `<TOKEN>` 占位，禁止把真实 Token 或完整回调写进仓库。

要点：

- `access_token` 在 **hash（`#` 后面）**，不是 `?` query。
- `expires_in=2592000` 即 30 天。
- `session_secret` / `session_key` 通常为空，**没有 refresh_token**，不能后台静默续期。
- 输入框同时接受：整段 `login_success` URL、`#access_token=...` 片段、或纯 Token。
- 服务端解析后只保存 Token 和过期时间。完整回调 URL 不入库、不写日志、不进错误信息。

解析规则（以后端为准）：

1. 若包含 `access_token=`，按 hash/query 取出 `access_token`、`expires_in`、`scope`。
2. 否则把 trim 后的整段当作 Token。
3. Token 非空，长度 1–512，可见 ASCII。
4. `expires_in` 能解析成正整数就用，否则默认 `2592000`。
5. `expires_at = now + expires_in 秒`。
6. 粘贴体上限 2048 字符（整段 URL 比 Token 长）。

授权页（client_id 已在 Skill 中公开，可给前端）：

```text
https://openapi.baidu.com/oauth/2.0/authorize?response_type=token&client_id=QHOuRXiepJBMjtk0esLhrPoNlQyYd0mF&redirect_uri=oob&scope=basic,netdisk&qrcode=1
```

`GET /api/netdisk/options` 返回 `authorizeUrl` 和 `purpose`，前端不要另写一套地址。

### 3.4 过期怎么检测、怎么刷新

| 情况 | 判断 | 工作台行为 |
| --- | --- | --- |
| 仍有效 | `now < expires_at` 且最近 list 成功 | `status=active`，显示「有效期至 …，剩余 N 天」 |
| 即将过期 | 剩余 ≤ 3 天且未过期 | 仍可实时 list，凭据区警告「即将过期，请重新授权」 |
| 已过期 | `now >= expires_at` | 视为 `expired`，**不要再用这枚 Token 打百度**。有缓存就显示缓存。凭据区变为必填 |
| 百度判定失效 | list 返回 errno 111 | `status=invalid`，即使时钟未到。引导重新授权 |
| 刷新 | 用户再走授权页，粘贴新回调或新 Token | PUT 覆盖密文和 `expires_at`，探活成功后变 `active` |

不要做：refresh_token 自动换票、定时任务刷百度、过期后仍拿旧 Token 去 list 直到失败。

### 3.5 凭据 API

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| GET | `/api/netdisk/credential` | `{ configured, status, tokenLast4, scope, obtainedAt, expiresAt, expiresInSec, lastVerifiedAt, lastError, purpose, authorizeUrl }`。库内 active 但已过 `expiresAt` 时按 `expired` 返回。无 Token、无完整 URL。 |
| PUT | `/api/netdisk/credential` | body `{ credential }`（推荐）或 `{ accessToken }`。按 §3.3 解析。加密写入后 `list /AIGC` 探活；errno 111 不算成功。响应无 Token。 |
| DELETE | `/api/netdisk/credential` | 删除凭据，不删 `netdisk_nodes`。 |

`purpose` 固定：`仅用于读取百度网盘 /AIGC 目录列表，不会用此 Token 上传、下载或删除文件。`

PUT 后不要把 Token 或完整回调 URL 写进日志或错误对象。调用百度时 Token 在 query 是接口要求；捕获异常只记录 `path`、`errno`、`statusCode`，禁止 `console.error(url)`。

探活只允许 `list` 白名单根目录。禁止用写接口探活。可选 `GET /api/quota`。

## 4. 实时 list

### 4.1 何时打百度

| 用户动作 | 服务端行为 |
| --- | --- |
| 打开工作文档 / 切到 `/AIGC` | `list` 当前路径一层 |
| 点击文件夹 | `list` 该文件夹一层 |
| 点刷新 | 再 `list` 当前路径一层 |
| 搜索文件名 | **不打百度**，查 `netdisk_nodes` |
| 顶部统计/类型汇总 | **不打百度**，查 `netdisk_nodes` |

禁止：打开页面就 `tree` 整棵 `/AIGC`。

### 4.2 调用约定（必须与现有 Python 一致）

复用 `skills/baidu-netdisk-archive/scripts/netdisk_sync.py` 里已验证的 list 行为，不要凭直觉改：

- 主机：`https://pan.baidu.com`
- 路径：`GET /api/list`
- query：`access_token`、`dir`、`web=1`、`page`、`num=1000`、`order=name`、`desc=0`
- 同一层必须翻页直到不足 1000 条
- 可重试 errno：`-6, -8, -11, 112, 158`（最多 4 次，指数退避，上限 10s）
- 超时：单次 HTTP 8s，整层（含翻页）15s
- `dir` 必须先经过现有 `assertNetdiskPath`，只允许 `NETDISK_ROOT_PATH`（默认 `/AIGC`）及其子路径

Node 侧自己实现 list 客户端，**不要** `execFile` 去调 Python，也不要在容器里读 `~/.config/aigc-workbench/baidu_netdisk_token`。

### 4.3 节点清洗

返回给前端、写入缓存的字段只允许：

`path, name, parentPath, isDir, kind, sizeBytes, serverMtime, fsId, category`

规则与现有 catalog 一致：

- 路径白名单
- `kind` 按扩展名分类，目录固定 `directory`
- `fsId` 当字符串，避免 64 位精度丢失
- `serverMtime` 是百度秒级时间戳，入库时 `* 1000` 成 timestamptz
- 丢掉 `thumbs`、`dlink`、`md5`、所有凭据字段
- 现有 `assertNoFileContent` / `FORBIDDEN_KEYS` 继续生效

百度 `web=1` 的 list 项可能带缩略图 URL。第一期**不要**展示网盘缩略图，避免把带鉴权的 URL 送进前端或库。

### 4.4 `GET /api/netdisk/children` 新语义

现有路由保留，改为：

1. 校验登录、校验 path。
2. 若用户有 `status=active` 的凭据：实时 list。
3. 成功：把这一层子节点 upsert 进 `netdisk_nodes`；删除「`parent_path=当前路径` 但不在本次结果里」的节点；若被删的是目录，同时删除其子孙（`path = 子路径 OR path LIKE 子路径/ %`，LIKE 必须 `ESCAPE '\'` 并转义 `%`/`_`）。
4. 响应：

```json
{
  "path": "/AIGC/902视频",
  "source": "live",
  "fetchedAt": "2026-10-12T08:40:00.000Z",
  "nodes": [],
  "snapshot": null,
  "credential": { "configured": true, "status": "active" },
  "warning": ""
}
```

5. 实时失败：
   - errno 111 或明确未授权：把凭据标为 `invalid`，响应 200 或 401 都可以，但 JSON 必须有稳定字段 `errorCode: "token_invalid"`，并返回缓存节点（若有），`source: "cache"`。
   - 超时、5xx、可重试耗尽：`source: "cache"`，`warning` 说明「网盘暂时读不到，正在显示上次缓存」。有缓存 200；无缓存 200 + 空 nodes + `errorCode: "live_unavailable"`。
   - 路径不存在：视为空目录，`source: "live"`，并按第 3 步清掉该层旧缓存。

6. 无凭据：不打百度。有缓存则 `source: "cache"` + `errorCode: "need_credential"` 的提示用前端凭据表单表达；无缓存则空列表 + `credential.configured=false`。

`GET /api/netdisk/tree` 与 children 同语义（都是一层），不要做成递归。

不要新增「服务器下载」路由。`/api/netdisk/sync-commands` 继续只返回本机命令。

## 5. 缓存与统计

- 实时成功后更新 `netdisk_nodes`，这样搜索、统计、失败兜底都有数据。
- 可以插入一条 `netdisk_snapshots`，`source='live'`，计数用**当前库内该用户全部节点**或「本次这一层」都可以，但前端「最近同步」在 `source=live` 时应优先显示 `fetchedAt`（刚刚从网盘读取），不要让用户以为还要手工发快照。
- 搜索 `GET /api/netdisk/search`、统计 `GET /api/netdisk/stats` 继续只读 `netdisk_nodes`。文档和 UI 写清：统计是缓存汇总，不是全盘实时扫描。
- 上一版 `complete=true` 全量清理逻辑只留给 `POST /api/netdisk/catalog`。实时 list **禁止**按 complete 清空整棵树。

## 6. 前端

改 `src/netdisk-browser.jsx` 和少量样式，不改路由。

1. **凭据配置区（就在工作文档 / 百度网盘目录卡片里，必须能配）**
   - 标题：百度网盘授权。
   - **用途**（始终可见，有 Token 时也要显示）：仅用于工作台读取 `/AIGC` 目录列表；不会用它上传、下载、删除网盘文件；视频仍由本机 Skill 传输。
   - 按钮「打开百度授权页」→ `authorizeUrl`（新标签页）。
   - 输入框 `type="password"`，placeholder 写清：粘贴授权成功后的整段地址，或只粘贴 access_token。保存后清空。
   - 已配置且有效：显示后四位、有效期、剩余天数；提供「更新授权」「移除凭据」。不要把配置区藏死，否则过期后用户找不到入口。
   - 剩余 ≤ 3 天：黄色警告 + 重新授权步骤。
   - `expired` / `invalid`：红色提示「Token 已过期或失效，请重新授权」，目录若有缓存可继续看并标明缓存。
   - 刷新步骤写死在 UI 上：① 打开授权页并登录 ② 跳到 `login_success` 后复制地址栏整段链接 ③ 粘贴到输入框保存，覆盖旧 Token。
   - 保存成功立即拉 `/AIGC`。
   - Token 和完整回调不得进 localStorage、URL、console。

2. **目录区**
   - 点击文件夹继续进入；点文件仍只打开元数据详情，详情里继续给本机下载命令，不出现「在网页下载」。
   - 工具条显示来源：`实时` 或 `缓存（网盘暂不可用）`。
   - 刷新 = 重新 children 当前路径。
   - 无凭据且无缓存：主空态是配置 Token，本机上传命令可以折起来。
   - 有实时数据：本机命令折到卡片底部，不要再占主空态。

3. **禁止**
   - 任何 `<video>` / `<img src=dlink>`
   - 把 Token 放进 `localStorage`、URL、console
   - 前端直连 `pan.baidu.com`

## 7. 安全清单

1. 服务器持有 Token 后，应用层必须把能力锁死在 `GET /api/list`（外加可选 quota）。源码里不要出现 precreate、superfile2、filemanager、create 的网盘调用。
2. 路径白名单沿用 `assertNetdiskPath`。用户即使 Token 能看整盘，工作台也只能看 `/AIGC`。
3. 响应、数据库 `extra`、日志、Git 都不允许出现 `access_token` / `dlink` / 完整授权回调 URL。
4. `PUT /api/netdisk/credential` 必须登录。不能做成公开配置接口。
5. 不要做通用 Token 表（禁止 `provider` 自由字符串扩展成任意网站）。
6. 生产环境没有 `NETDISK_TOKEN_ENCRYPTION_KEY` 时，功能关闭，而不是明文存。
7. 下载继续本机。第一期如果有人加 `/api/netdisk/download`，视为方案违规。

## 8. 配置

`.env.example` 与 `.env.server.example` 增加：

```bash
# 用于加密用户保存在数据库里的百度网盘 Token（32 字节 Base64）
# 生成：openssl rand -base64 32
# 不要把真实密钥提交进 Git。没有该变量时，实时目录读取不可用。
NETDISK_TOKEN_ENCRYPTION_KEY=
NETDISK_ROOT_PATH=/AIGC
```

删除或改掉上一版「Token 绝不进入服务器」的绝对表述，改成：

- 上传/下载 Token 仍建议只放本机 Skill
- 工作台若开启实时目录，Token 加密后按用户存在 `netdisk_credentials`，只用于 list

本机 Skill 文档保持「上传下载用本机 Token」；补充一句：工作台实时浏览需要在网页里再配置同一枚 Token（或过期后重配）。

## 9. 验收标准

1. 工作台用户保存 Token 后，打开工作文档能看到 `/AIGC` 下一层真实目录，点击可进入，与本机 `netdisk_sync.py list <path> --json` 一致。
2. 不执行 `publish-catalog` 也能完成第 1 条。
3. 保存/读取凭据的 API 响应、前端 bundle、日志里都没有完整 Token。
4. 拔掉加密密钥或 Token 标 invalid 后，有缓存则显示缓存+警告，无缓存则引导重新配置。
5. 没有任何接口把网盘文件字节打进 Node 再送给浏览器。
6. 现有本机上传 CLI 行为不变。
7. 单测覆盖：加密往返、路径白名单、list 翻页、失败降级、删除子目录时清理子孙、响应不含禁止字段。
